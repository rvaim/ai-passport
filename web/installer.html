Passport 工具

连接一次设备，然后安装 PAP，或向 2FA 验证器发送账号密钥。

连接设备

输入 Passport 显示的设备码；连接后网页会从设备再次读取并核对。

设备码可在“设置 → 设备信息”或“插件管理”页查看。

尚未连接

输入完整设备码后连接 Passport。

Passport 安装器

选择本地插件或主题 .pap，并安装到上方已连接的设备。

选择安装包

请选择不超过 4 MB 的 .pap，也可以拖到这里。

等待选择安装包 0%
0%
等待安装包

选择 .pap 后即可使用上方连接安装。

2FA 密钥发送

先在设备打开“2FA 验证器 → 接收 2FA 密钥”，再发送账号。

读取后会填入下面的账号、签发方和 Base32 密钥。

密钥通过当前 Passport Link 直接发送并保存在插件私有存储中，不会上传到互联网。当前 BLE Link 按需求不加密。

等待设备和账号

连接设备后，可同步时间或发送一个 TOTP 账号。

请使用桌面版 Chrome 或 Edge，并通过 HTTPS 或 localhost 打开本页。Safari 和 iPhone/iPad 暂不支持 Web Bluetooth。设备断电或重启后，请重新打开 2FA 验证器并点击“同步时间”。
